# PLANETDLE texture credits

Textures are projection maps used on schematic spheres. Surface coverage, color and resolution vary. Orbital sizes and times are schematic. The NASA photograph gallery is a separate feature.

| World or group | Source and processing |
| --- | --- |
| Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, Earth's Moon | [Solar System Scope / INOVE](https://www.solarsystemscope.com/textures/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Existing 2K maps sourced from the locally cached Atlas install. The publisher uses NASA imagery and data with adjusted colors and reconstructed areas. Venus uses a cloud-top map. Gas and ice giant maps represent atmospheric appearance. |
| Io, Europa, Ganymede | [NASA/JPL-Caltech/USGS Solar System Simulator](https://maps.jpl.nasa.gov/tmaps/jupiter.html). Existing 1440 × 720 Voyager/Galileo-derived maps retrieved from the locally cached Atlas install. |
| Phobos | [NASA published Phobos model](https://science.nasa.gov/resource/phobos-mars-moon-3d-model/). Mesh normalized for display, with original UVs and embedded color map converted to JPEG. Separate normal maps are not used. |
| Enceladus | [USGS Cassini ISS global mosaic](https://astrogeology.usgs.gov/search/map/enceladus_cassini_global_mosaic_110m), official 1024 × 512 JPEG. |
| Callisto | [USGS Galileo/Voyager global mosaic](https://astrogeology.usgs.gov/search/map/callisto_galileo_voyager_global_mosaic_1km), official 1024 × 512 JPEG. |
| Titan | [NASA/JPL-Caltech/Space Science Institute, PIA22770](https://science.nasa.gov/resource/titan-mosaic-the-surface-under-the-haze/). Cassini ISS near-infrared surface brightness, resized from 5760 × 2880 to 2048 × 1024 for WebGL compatibility. |
| Ceres | [NASA published Ceres model](https://science.nasa.gov/resource/ceres-3d-model/). Mesh normalized for display, with original UVs and embedded color map converted to JPEG. Separate normal maps are not used. |
| Vesta | [NASA published Vesta model](https://science.nasa.gov/resource/vesta-3d-model/). Mesh normalized for display, with original UVs and embedded color map converted to JPEG. Separate normal maps are not used. |
| Pluto | [NASA Visualization Technology Applications and Development (VTAD) Pluto 3D model](https://science.nasa.gov/resource/pluto-3d-model/). The bundled mesh arrays and 4096 × 2048 color texture were extracted from NASA’s GLB. The texture was re-encoded as JPEG. The published asset includes approximate southern color detail. |
| Bennu | [NASA published Bennu model](https://science.nasa.gov/resource/bennu-3d-model/). Mesh normalized for display, with original UVs and embedded color map converted to JPEG. Separate normal maps are not used. |
| Halley's Comet | Philip Stooke’s [Giotto/Vega nucleus reconstruction](https://doi.org/10.26033/yt84-5y91) via [Celestia Content](https://github.com/CelestiaProject/CelestiaContent/blob/master/models/halley.cmod). Geometry converted from CMOD and normalized for display. Neutral nucleus shading and animated dust and ion tails are illustrations. |
| Sun | Existing stylized central marker, outside the 21 searchable worlds. |

JPL and USGS publication credits are retained. This independent game is unaffiliated with NASA. Scientific hotspot placements are approximate.


Neptune uses the existing Solar System Scope cloud map with a display color correction informed by [Irwin et al. (2024)](https://doi.org/10.1093/mnras/stad3761). This is an approximate adjustment, not a calibrated Voyager map.
