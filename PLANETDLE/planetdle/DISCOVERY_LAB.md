# PLANETDLE 3D Discovery Lab

- Double-click an object on the 2D orbital map, or select it once and press **Explore in 3D** in its information profile.
- Drag the globe to rotate, scroll to zoom, pause/resume auto-rotation, and click glowing markers for scientific explanations.
- The globe is rendered locally in WebGL (no external JavaScript library or API required) using the existing illustrated cylindrical surface textures.
- The models are educational visualizations, **not** photogrammetry, exact physical geometry, or NASA photographic texture maps. Saturn's rings are schematic.
- Scientific feature markers are illustrative positions, not verified geographic coordinates. The labels and explanations describe real phenomena; their displayed locations on the illustrations are not precise.
- NASA Image and Video Library integration remains in the existing full-width details panel.
- Browsers without WebGL can still use the original 2D map and educational profiles.
