# Astronomy notes review

The 15 general notes are shuffled independently of the answer. A rejected or repeated guess does not draw another note. The existing hint API also gives general astronomy insights. The actual reasoning clues are the six comparison tiles. The final result uses a separate fact about the revealed answer.

| Original note topic | Review and decision |
|---|---|
| Day and year | Removed. “Day” can mean a rotation or noon-to-noon; the spin explanation is clearer in the Moon example. |
| Dangerous clouds | Removed. A vague description that did not explain which clouds or why. |
| Craters | Rewrote as a reason the Moon still has many old craters. |
| Planet gravity stretches moons | Kept and rewrote to connect repeated flexing to internal heat. |
| Atmosphere as a blanket | Removed. The wording implied thickness alone determines warming. |
| Hidden oceans | Rewrote to explain why spacecraft measurements matter. |
| Moon orbital rhythms | Removed from the core set. The concept needed a full explanation. |
| Magnetic shielding | Removed to avoid a misleading blanket statement about shielding. |
| Rings | Rewrote to explain why separate ice pieces appear to form a band. |
| Gravity assist | Kept and clarified that flybys can change speed or direction. |
| Extra colors | Rewrote with the practical distinction between wavelength and visible color. |
| Comet tails | Rewrote to connect warming, escaping material, and how tails point. |
| Sky color | Removed, overlapping with the imaging note. |
| One side of a moon | Rewrote with Earth's Moon and an equal spin/orbit period; added the mutual case at Pluto and Charon. |
| Counting craters | Folded into the Moon crater note; avoided implying a universal age rule. |
| Icy exterior and warm interior | Folded into the hidden-ocean and flexing notes. |
| Radio travel | Kept and gave a concrete example involving a spacecraft command. |
| Same size and different weights | Removed. Mass was the intended concept and the phrasing used weight loosely. |
| Ice volcanoes | Removed from short notes; Enceladus’s result fact still teaches jets. |
| Earth–Sun distance as a unit | Removed to keep the set concise. |
| Lumpy asteroids | Kept; connected shape directly to weak self-gravity. |
| Backward spin | Rewrote with Venus’s reversed sunrise as the consequence. |
| Eight-minute sunlight | Kept and explained what the delay means. |
| Empty asteroid belt | Removed. The old sentence used an unnecessary estimate. |

Added permanently shaded ice and a meteor-shower note. Reviewed the separate result facts for all 21 worlds, preserving their subject and rewriting Titan's liquids and Halley's meteor showers in plain English. In-game attribute categories are simplified clues. Mean diameters are approximate, and asteroid shapes and map lighting depend on the source model.
